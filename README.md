# Codeka IA 🤖⚡

**La IA que te hace más productivo — automatización real para tu negocio y tu día a día, en español.**

Codeka IA es la extensión de [Codeka Digital](https://codekadigital.com) dedicada a mostrar cómo
la inteligencia artificial te devuelve horas: productividad personal, automatización de negocios
y, de vez en cuando, herramientas construidas a medida que puedes copiar. Sin humo y sin
tecnicismos innecesarios.

## 📚 Series de contenido

| Serie | Qué encontrarás |
|---|---|
| **IA productiva** | Gana horas cada semana: correos, resúmenes, organización, plantillas de prompts listas |
| **Automatiza tu negocio** | Flujos reales sin programar: atención al cliente, redes sociales, tareas repetitivas |
| **Lo construí para ti** 🔧 | Piezas híbridas: herramientas que construyo con IA, mostradas por dentro, con el código en GitHub |

## 🗂 Estructura de este repositorio

```
codeka-ia/
├── OFERTA.md                 # El programa: módulos, servicios y escalera de valor
├── MODELO-CONSULTORIA.md     # El negocio: packs, precios, proceso y embudo de consultoría
├── CALENDARIO-EDITORIAL.md   # Plan de contenido
├── guiones/                  # Guiones de videos y posts, uno por semana
├── tutoriales/               # Guías paso a paso y herramientas de "Lo construí para ti"
└── recursos/                 # Plantillas de prompts, checklists y descargables
```

## 🧭 Principios

1. **Resultados primero.** Cada pieza abre con cuánto tiempo o dinero te ahorra.
2. **Simple por defecto, técnico cuando suma.** Lo de dentro de las herramientas se muestra a nivel proceso.
3. **Todo demostrado en pantalla real.** Los ahorros de tiempo son medidos, no inventados.
4. **Honestidad.** La IA se equivoca, tiene límites y costos; aquí se dicen.
5. **Una acción por pieza.** Sales de cada video con algo aplicable hoy.
